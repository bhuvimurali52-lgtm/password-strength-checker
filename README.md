# 🔐 Advanced Password Strength Checker

## 📌 Overview
A Python-based tool to evaluate password strength using regex validation and entropy calculation.

## ⚙️ Features
- Checks:
  - Minimum length
  - Uppercase & lowercase letters
  - Numbers
  - Special characters
- Calculates entropy
- Classifies password as Weak / Moderate / Strong

## 🛠️ Tech Stack
- Python
- Regex
- Math

## ▶️ How to Run
```bash
python password_checker.py
